# Klickdoe Claude Code Portfolio Kit

## Use
1. Copy this folder into the root of the existing website repository (or use it as the starting project folder).
2. Open the repository in Claude Code.
3. Ask Claude Code: **“Read CLAUDE.md and all docs. Inspect the existing repository, update the tracking files, then implement Demo 01 according to the brief. Preserve existing work and do not mark it complete until all quality gates pass.”**
4. Keep `CLAUDE.md` and the `docs/` files in version control. Claude Code must update the trackers after each work session.

## Files
- `CLAUDE.md` — persistent master instructions and execution protocol.
- `docs/DESIGN_SYSTEM.md` — brand quality bar and 64 distinct theme directions.
- `docs/THEME_TRACKER.md` — avoids losing track of themes and repeating layouts.
- `docs/DEMO_ROADMAP.md` — demo list and milestones.
- `docs/SESSION_LOG.md` — continuation notes.
- `docs/DESIGN_DECISIONS.md` — durable decisions.
- `docs/KNOWN_ISSUES.md` — blockers and incomplete work.

The kit is a build specification, not a completed website. It intentionally tells Claude Code to inspect the existing repository before choosing or changing frameworks.
